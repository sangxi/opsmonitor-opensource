开放 REST API 说明

第三方系统可通过以下接口获取监控数据（需携带请求头 X-API-Token 或参数 apiToken）：

GET /opsmonitor/openapi/hosts 主机列表   GET /opsmonitor/openapi/host?id=xxx 主机详情   GET /opsmonitor/openapi/alarms 告警记录   GET /opsmonitor/openapi/summary 全局汇总

返回 JSON：{"code":0,"msg":"success","data":[...]}，鉴权失败返回 401。
